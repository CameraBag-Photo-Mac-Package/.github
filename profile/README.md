## What It Is

A desktop photo app rebuilt from the ground up around the Analog Engine, which handles image processing and
pairs a full suite of photographic tools with the high-quality filters and vintage simulations the series has
been known for since its earliest versions. The key innovation is not any single filter but the approach to
layering: styles and adjustments stack, rearrange and re-tweak endlessly, in realtime, and nothing is
committed until you export.

## Core Features

- **100+ built-in styles and filters** — use them as shipped, adjust them, or create and share your own.
- **25+ professional manual controls**, including advanced curve editors for people who want to work by hand.
- **Save any look as a filter** — a result you like gets added back to the toolset as a fully-adjustable entry.
- **Non-destructive editing with active history**, so an early decision stays reversible at any point.
- **The Remix slider**, which transitions smoothly between endless variations of what you already built.
- **32-bits-per-component colour depth** and full RAW format and metadata support.
- **Quicklooks and hover previews** for visual decision-making before you commit to anything.
- **Batch saving** and arrow-key browsing through a folder with your current filter already applied.

## A Typical Workflow

Open a photo and let the Analog Engine handle the processing while you browse. Hover a filter to preview it
in place; the quicklook shows you the result without changing the document. When something is close, apply
it, then start pulling on the manual tools — curves first, usually, since the advanced curve editors are
where the real correction happens. Because layering is easy, you add a second style over the first rather
than undoing and restarting, and you reorder that stack when the interaction between two effects is not what
you expected. When the image is right, save the whole arrangement as a fully-adjustable filter so the next
photo in the set inherits it. Then use the arrow keys to walk through the rest of the folder in that filter
and finish with batch saving. This is the loop that makes a photo editor mac session feel fast rather than
fiddly.

## Tips And Shortcuts

Use the arrow keys as your primary navigation once a look is set — flicking through a folder in your current
filter is faster than opening images one at a time. Lean on hover previews before applying anything; the
preview costs nothing and the undo does. Treat the Remix slider as an idea generator rather than a finishing
tool: run it when a look is nearly right but slightly stale. And remember that the controls are deliberately
large and precise, and the interface is laptop-friendly, so a trackpad session on a small screen is a first-
class case rather than an afterthought.

## FAQ

**Is this a preset pack or a real editor?** Both, functionally. The photo filters mac side gives you 100+
starting points; the 25+ manual tools mean you never have to accept one as-is.

**Will edits damage the original?** No. Editing is non-destructive with an active history, so every step
remains adjustable.

**Does it read RAW files?** Yes — RAW format and metadata support are built in, alongside 32-bit-per-
component colour.

**Can I reuse a look?** Yes. Add any look you create to the toolset as a fully-adjustable filter, then apply
it across a folder and batch save. A camerabag photo mac download is worth it for that alone if you shoot in
sets.
